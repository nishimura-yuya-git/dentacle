# UI Polish Hard Gate

Context Budget で must。長い `ui-polish.md` 後半は落ちてよい。

## 完成禁止

欠落は `observe-chrome` / `borrow-inventory` / `observe-edge` / `observe-blockers-cleared` / `observe-ai-processing` で stop。

1. 内側パネルだけのスクショ
2. ページ枠照合が無い
3. 対象枠を見本の枠で入れ替えた。ユーザーが枠変更を明示したときだけ可
4. キャプチャ未読で見た目OK
5. 借りない物を実装した（暗い面・段階数・詳細設定・幅px・コピー・Cursor Cloud 枠・Proバッジ・キラキラ・緑薄いタブへの戻し）
6. ページ見出しと同名見出し・導入文を重ねた
7. 端の開閉を動かしていない（下端▼等）。無しなら「なし（端の開閉なし）」
8. 開閉で固定枠が動く・ガクつく・見切れる
9. 同じ注意をヘッダーと案内バブルで重ねた
10. モバイルで FAB / 閉じる丸が送信・入力を覆う。専用ページで入口FABを出した
11. 観察で重複・重なりを書いたまま完成した。`観察で残した阻害: なし` が無い
12. AI処理中なのに Composing を出さず「処理中…」だけで完成した。実行中未観察（無しなら「なし（AI処理なし）」）

## 参照の正体

## 対象枠ロック

対象の既存枠が正。業務ハブは `DashboardLayout`。`SecurityLayout` は `/security` だけ。原子とページ枠は別。枠幅を変えたら本文幅も見る。

## 切替原子

主操作は `Button`。排他の2〜4択は `SegmentedControl`（灰トラック＋選中白ピル）。オンオフは `Switch`。多択入力は `Select`。

## 借りてよい / 借りない

借りてよい: 部品の形、余白リズム、面の静けさ、2〜4択切替の灰トラック＋選中白ピル、AI実行中の Composing 点オーブ。既定で借りない: ページ枠、レール幅px、暗い面、段階数、詳細設定、装飾英語、見本文言、共有メニューの下開き、Proバッジ、キラキラ、緑薄いタブ（`bg-[#008C01]/10`）への戻し、英語 "Composing"・他 state。

## AI処理

裏でAI/エージェントを動かすボタンは `ComposingOrb`（composing・light・日本語）。`thinking-orbs` 直 import 禁止。ログインやCSVの「処理中…」は対象外。
