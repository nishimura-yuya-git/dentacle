# UI Polish Hard Gate

Context Budget で must。長い `ui-polish.md` 後半は落ちてよい。

## 完成禁止

欠落は `observe-chrome` / `borrow-inventory` / `observe-edge` で stop。

1. 内側パネルだけのスクショ
2. ページ枠照合が無い
3. 対象枠を見本の枠で入れ替えた。ユーザーが枠変更を明示したときだけ可
4. キャプチャ未読で見た目OK
5. 借りない物を実装した（暗い面・段階数・詳細設定・幅px・コピー・Cursor Cloud 枠）
6. ページ見出しと同名見出し・導入文を重ねた
7. 端の開閉を動かしていない（下端▼等）。無しなら「なし（端の開閉なし）」
8. 開閉で固定枠が動く・ガクつく・見切れる

## 参照の正体

見本の名前を書く。文書シェル見本は **Nani!?**。Cursor Cloud と決めつけない。構造・余白は借りてよい。**px幅・共有ナビ・メニュー開く方向は案件SSoT**（業務ナビ `w-56`）。Nani の 298px を丸コピーしない。

## 対象枠ロック

対象の既存枠が正。業務ハブは `DashboardLayout`。`SecurityLayout` は `/security` だけ。原子とページ枠は別。枠幅を変えたら本文幅も見る。

## 借りてよい / 借りない

借りてよい: 部品の形、余白リズム、面の静けさ。既定で借りない: ページ枠、レール幅px、暗い面、段階数、詳細設定、装飾英語、見本文言、共有メニューの下開き。

## Iteration 0

対象枠ロック → 借り一覧 → 面 → タイポ → 主ボタン → 余白 → 端の開閉

## 観察・宣言

見本 and 実装（ページ全体）。端のオーバーレイを開く。宣言に参照の正体・対象枠・借りてよい/借りない・操作観察を書く。

## Stop

確認停止: 他画面ナビ・対象枠の変更が必要。差し戻し: 対象枠上書き / 借りない物 / 端の見切れ。
