# IP as Logo

IPキャラを「ロゴが先、キャラは二の次」で正方形ロゴにする。生成ルールの正本はスキル。このコマンドは呼び出しと案件境界だけを持つ。

## 実行前に必ず読む

```text
.cursor/skills/ip-as-logo/SKILL.md
```

出典の本体: [s1dashu/ip-as-logo-skill](https://github.com/s1dashu/ip-as-logo-skill)（MIT）。`npx skills add` は使わない。

## 手順

1. 依頼から題材・人数・背景色・「6案まで出して」などの許可を読む
2. 題材が無いときは `PROJECT_MEMORY.md` と対外名（Dentacle）を読み、製品に紐づく3方向を出す
3. 方向をチャットに出し、6独立画像の生成を提案する
4. ユーザーが同意したとき、または今回の依頼が生成を明示しているときだけ生成する
5. 1画像1回の生成にする。コンタクトシートやグリッドは禁止
6. スキルの却下ルールで点検し、実用なら1回だけ直す
7. ラベル・パス・色・寸法・不透明・残逸脱を報告して**停止**する

## この案件での停止線

選定・採用・公式化は人間が行う。生成後に次をしない。

- 当選案を決めない。おすすめ1枚を公式扱いしない
- `BrandLogo` / `public/icon/logo.png` / `APP_DISPLAY_NAME` を触らない
- 生成画像をリポジトリへ入れない（ユーザーが保存先を指定したときだけ）
- 色・題材・人数を勝手に公式ブランドへ固定しない

## 呼び出し例

```text
/ip-as-logo
/ip-as-logo 可愛い猫のIPロゴを作って。背景は深いネイビーで。
/ip-as-logo おばあちゃん、おじいちゃん、大人女性、大人男性、女の子、男の子
/ip-as-logo B1 だけ6バリエーション
```

## 出力の最低項目

```text
□ 3方向（またはユーザー指定の役）と一言理由
□ A1〜 のラベルと保存パス
□ 3色の対応（背景1 + IP2）
□ 寸法・不透明（RGB / 透明なし）
□ 残逸脱（なければ「なし」）
□ 次は人間が選ぶ、と明記
```
