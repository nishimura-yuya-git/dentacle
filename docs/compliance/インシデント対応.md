# インシデント対応（運営向け）

公開の電話窓口は置かない。院向けの正は `/security/privacy#incident`。

## 対象

漏えい、紛失、不正アクセス、委託先障害のうち、患者情報または予約情報に触れうるもの。

## 手順

1. 覚知した運営は、影響クリニック、データ種別、件数の見積もりを切り分ける。
2. 対象医院の管理者へ、事実・見積もり・次の行動を連絡する。
3. 必要なら Supabase / Vercel / Cursor / GitHub の記録を保全する。
4. 再発防止を実施し、医院へ結果を報告する。

## まだ決めてはいけないこと

報告期限（何時間以内か）は未決。勝手に「準拠済みの72時間」などと書かない。
決めたら契約と `COMPLIANCE_PENDING_DECISIONS` の `incident_report_deadline` に残す。

## 連絡を受ける場所

院からはご意見画面、または契約している運営窓口。
ご意見本文に患者氏名・カルテ番号を載せない。
